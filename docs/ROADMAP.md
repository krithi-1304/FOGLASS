# Updated V1 roadmap

Prior M0/M1/M2 remain in historical MEMORY.md. New brief uses V1 milestone names.

1. Foundation: canonical memory, architecture, provider/mock, Vitest, fixtures, CI.
2. Mirror baseline: retain working camera/fog; fix gaps with regression evidence.
3. Vision: MediaPipe local assets, smoothing, features, calibration, diagnostics.
4. Physical wiping: stable palm motion, broad streaks, two-hand clear/reset/freeze.
5. Writing: stable index, smooth strokes, undo/redo, priority and conventional controls.
6. Magic Reveal: Real Mirror / Fog Writing / local message or image reveal.
7. Capture: PNG and supported local video; lifecycle cleanup.
8. Polish: realism, optional calibrated breath, adaptive quality, accessibility, mobile.
9. Laboratory/replay: opt-in landmark capture, JSON validation and fixture playback.
10. Final QA: full suites, intentional screenshot baselines, performance and manual limits.
    Optional backend and future frost/rain/neon/party modes deferred.
    Each completed feature: tests/build/lint, diff review, docs update, conventional commit.
